# GitHub Setup Instructions

## This package contains two options:

### Option 1: Create `brian-curry` Repository (Recommended)

This creates a standalone, searchable repository for your professional profile.

1. Create a new repository on GitHub named `brian-curry`
2. Upload all files from this package:
   - `README.md` — Main profile (this displays on the repo page)
   - `RESEARCH.md` — Detailed research overview
   - `LICENSE` — MIT license

### Option 2: GitHub Profile README

This displays directly on your GitHub profile page (github.com/Bodhi8).

1. Create a new repository named exactly `Bodhi8` (must match your username)
2. Rename `PROFILE-README.md` to `README.md`
3. Upload to the `Bodhi8` repository
4. The content will automatically display on your profile page

### Recommended: Do Both

- Create `Bodhi8` repo with `PROFILE-README.md` → Shows on profile
- Create `brian-curry` repo with full `README.md` and `RESEARCH.md` → Searchable, linkable
